# Movie Tracker 🎬

A Python + MySQL based Movie Tracker application to manage and track movies.

## Features
- Add new movies
- View all movies
- Update movie details
- Delete movies
- Store movie data using MySQL database

## Technologies Used
- Python
- MySQL
- Git & GitHub

## Database
Database: movie_tracker

Table: movies

## How to Run
1. Clone the repository
2. Install required libraries
3. Configure MySQL connection
4. Run main.py
